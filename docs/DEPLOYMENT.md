# 무료 시험용 웹사이트 배포

이 버전은 가상 사례 전용이다. 실제 회원자료를 입력하지 않는다. AI API·유료 요금제·결제 설정은 필요하지 않다. 공개 저장소의 GitHub Pages로 HTML/JavaScript를 제공한다. 기록은 서버가 아니라 접속한 브라우저에 저장된다.

## 배포할 파일과 브랜치

- `index.html`, `workspace.js`, `.nojekyll`을 저장소 루트에서 제공한다.
- 개발 변경사항은 `feature/web-rehab-workspace`에 보존한다.
- 배포용 `gh-pages` 브랜치에는 검증된 개발 커밋을 올린다.
- `main`을 덮어쓰거나 저장소 공개 범위를 변경하지 않는다.
- 별도 빌드·npm 설치·API 키·GitHub Actions 워크플로는 추가하지 않는다.

## 처음 한 번 GitHub Pages 활성화

저장소 소유자 계정으로 다음 페이지에 로그인한다.

https://github.com/minseok3773/yakkuk/settings/pages

1. **Build and deployment → Source**에서 **Deploy from a branch**를 선택한다.
2. **Branch**에서 **gh-pages**, 폴더는 **/(root)**를 선택한다.
3. **Save**를 누른다. 배포가 완료되면 GitHub에 표시되는 주소를 확인한다.

예상 기본 주소는 `https://minseok3773.github.io/yakkuk/`이다. 활성화·배포 성공 전에는 이 주소가 작동한다고 간주하지 않는다. 사용자 지정 도메인·유료 서비스 설정은 하지 않는다. 요금제 변경을 요구하는 화면이 보이면 진행하지 않는다.

## 첫 사용

1. 배포가 완료된 주소에서 **1. 약·증상 입력 → 2. 분석 요청 → 3. 결과 확인** 순서가 표시되는지 확인한다.
2. 약과 증상을 가상 정보로 입력한다. 변경 시점·검사결과·회원 상태는 선택 항목을 펼쳐 입력한다.
3. 연결 확인 후 가상 정보 확인란을 선택하고 **AI 자동 분석**을 누른다. **입력 요약만 보기**로 AI 없는 전달용 요약도 확인할 수 있다.
4. 저장·복원 시험은 하단 **개발·시험 도구**에서 한다. **기록 저장** 후 새로고침하고, 저장한 기록을 선택해 **선택 기록 열기**로 메인 화면에 복원한다.
5. 시험 도구의 **JSON 백업**으로 파일을 내려받는다. 기기·브라우저·주소 변경 전에도 백업한다. 화면 전환만으로는 입력이나 저장한 기록을 지우지 않는다.

일반 웹브라우저에서는 Cloudflare Workers AI 서버로 자동 분석·학습·퀴즈를 요청한다. 사진 분석과 Claude 전용 txt 저장은 이 서버가 지원하지 않는다. AI 오류·한도 초과 시에도 기록·요약·백업은 계속 사용할 수 있다. 실제 회원자료는 적용 범위가 아니며 `AI_SETUP.md`의 조건을 확인한다.

서버 연결이 되지 않을 때 가상 정보로 AI 설명을 받으려면 **AI 분석 요청문 만들기**를 누른다. 약 변경·증상 경과·검사·재활지원 기록까지 반영된 요청문을 복사해 승인된 외부 서비스에서 답을 받은 뒤 **AI 답 전체** 칸에 답 전체를 넣고 **붙여 넣은 답으로 결과 보기**를 누른다. 클립보드 권한이 없어도 표시된 요청문을 직접 선택해 복사할 수 있다. 이 과정은 자동 API 연결이 아니다.

## 이후 업데이트와 검증

개발 브랜치에서 테스트를 통과시킨 뒤 `gh-pages`를 갱신한다. 원격 배포 브랜치의 변경사항을 먼저 확인하고 강제 푸시는 하지 않는다. 웹사이트 주소를 유지하면 동일 브라우저의 저장소도 유지된다. 그러나 브라우저 데이터 삭제 시에는 백업 없이는 복구할 수 없다.

로컬 검증은 실행 중인 정적 서버에 대해 `python3 tests/smoke.py`로 수행한다. 공개 배포 뒤에는 실제 HTTPS 주소에서 요약·저장·새로고침·조회·백업을 다시 확인한다. 로컬 테스트 성공만으로 인터넷 배포 성공을 주장하지 않는다.
