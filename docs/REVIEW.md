## 검증

### 분석 화면과 개발·시험 도구 분리

메인 화면을 약·증상 입력 → 분석 요청 → 결과 확인으로 재배치했다. 변경 시점·검사·회원 상태는 선택 항목으로 접었고, 예시는 사용자가 버튼을 눌러 불러온다. 이전 가상 사례 기록실의 저장·복원·백업은 `#lab` 개발·시험 도구 화면으로 옮겼다. 같은 문서의 화면만 전환하여 진행 중 입력·결과·메모를 유지한다. 브라우저 저장소 키와 백업 형식은 그대로이며, 기록을 열면 메인에 복원한다. 화면 전환은 저장소를 갱신하거나 AI를 호출하지 않는다.

서버 연결 확인 중에는 주 버튼을 잠시 대기시키고, 연결되면 **AI 자동 분석**을 표시한다. 연결 실패 시 **AI 분석 요청문 만들기**로 복구한다. **입력 요약만 보기**는 별도 동작으로 구분했다. 실제 제출·답 붙여넣기·화면 전환·새로고침 후 요약과 기존 AI 결과/메모 복원·JSON 백업 복원·한도 오류를 브라우저 테스트로 검증한다. 모바일 화면의 가로 넘침도 확인한다.

### 웹사이트 실행 버튼 수정

Claude 아티팩트가 없는 GitHub Pages에서 기존 제출 버튼이 비활성화되고, 제출 핸들러도 즉시 반환하는 문제를 재현했다. 일반 브라우저에서도 **입력 요약만 보기**로 약 이름·증상을 포함한 전달용 요약을 만들 수 있다. 이 동작은 의학적 해석이나 성분 추론을 하지 않는다. 자동 분석이 연결되지 않거나 오류가 발생해도 요청문 표시·복사·외부 답 붙여넣기 경로는 남긴다. 새 입력 요약에 이전 AI 결과를 연결해 저장하지 않고, 기존에 저장된 기록과 데이터 형식은 유지한다. 새 요약도 저장 후 다시 열 수 있다.

추가 회귀 테스트는 실제 제출 버튼을 눌러 AI 미연결 브라우저에서 빈 입력 검사·가상 사례 확인·요약 생성·저장 후 복원을 확인한다. 약 변경·증상 경과·검사·재활지원이 요청문에 포함되는지, 클립보드 거절 시 수동 복사 경로가 보이는지, Claude 모의 플랫폼에서는 명시적 제출 후에만 호출되는지, 429 후 새 호출이 대기하면서 입력 요약은 계속되는지도 확인한다. 공개 서버의 실제 응답은 TLS가 검증되는 Node 클라이언트로 확인하며, 브라우저 자체의 직접 TLS 검증 제약은 아래 실제 연결 검증에 기록한다.

`python3 tests/smoke.py`는 실제 Chromium과 로컬 HTTP 서버로 실행한다. 가상 동의, 다분야 전달 요약, 기존 JSON 결과·중복 성분 규칙, 저장 후 재접속과 메모 복원, JSON 다운로드·복원·잘못된/중복 백업 거절, AI 동일 요청 재사용, 429 대기와 기록 저장 유지, 통신/응답 형식/저장 공간 오류, 모바일 제목 표시, 외부 요청 없음 등을 확인한다. AI 경계는 모의 함수이며 실제 외부 모델 품질·무료 한도·약관 준수를 검증한 것은 아니다. 저장은 명시적이며 브라우저 저장소 삭제 시 JSON 백업 없이는 복구할 수 없다.

## 자동 AI 서버 연결

후속 구현으로 Cloudflare Worker + Workers AI + SQLite Durable Object 일일 제한을 추가했다. API 토큰은 배포 환경에서만 사용하고 프런트엔드에는 검증된 공개 Worker 주소만 기록한다. 원본 Claude 경로와 브라우저 기록·백업을 유지한다. 서버 배포와 실제 가상 학습·분석 응답을 확인한 후 공개 Worker 주소를 등록했다. 가격·데이터 이용·모델 라이선스 확인 범위, 오류 처리, 개인정보 제약과 활성화 절차는 [AI 연결 안내](AI_SETUP.md)를 참고한다. 모의 테스트와 실제 연결 테스트 모두 의료적 성능 검증으로 해석하지 않는다.

## 실제 AI 서버 연결 검증

가상 정보로 한국어 학습 응답과 구조화 분석 응답을 확인한 후 Worker 공개 주소를 등록했다. 출력 형식은 JSON Schema로 지정하고 응답 객체·문자열을 서버에서 검증한다. 존재하지 않는 가상약은 확인 필요·성분 미상으로 표시하는지 확인했다. 실제 모델을 사용한 UI 검증에서 중복 요청 캐시 재사용, 저장·새로고침·복원을 확인했다. 인증서 영구 변경은 자동 승인 검토에서 거절되어 적용하지 않았고, 기존 TLS 검증 경로인 Node 클라이언트를 통한 HTTPS 중계로 UI를 검증했다. 직접 브라우저 TLS 검증과는 구분한다. Cloudflare 공식 약관·개인정보 정책·Developer Platform 서비스별 약관 원문도 확인했으며, 현재 범위는 여전히 가상 정보 학습용이다.

최종 운영 모델은 무료 지원 `@cf/meta/llama-3.3-70b-instruct-fp8-fast`로 고정했다. 작은 모델에서 관찰한 질문 반복·영문 성분명 오류를 이유로 교체했으며, 스키마 목록 길이와 ASCII 영문 성분명 형식을 제한했다. 공개 사이트의 6개 약 가상 예시에서 성분명 기준값 대조, 캐시 재사용, 저장·복원, 실제 퀴즈 3문항 표시를 확인했다. 실제 의학적 판단의 정확성을 검증한 것으로 해석하지 않는다. 검증 시도도 일일 요청 제한에 포함된다.
