# 약국이

정신재활시설 실무자를 위한 복약 관찰 연계·약 공부 도구입니다. 회원이 여러 진료과에서 받는 약을 한데 모아 정리하고, 무엇을 관찰해 주치의·약사에게 전달할지 준비하며, 약을 공부할 수 있게 돕습니다.

## 반드시 알아둘 점

- **진단 도구가 아닙니다.** 결과는 참고자료이며 틀릴 수 있습니다.
- **약의 중단·감량·변경은 주치의만 결정합니다.**
- **회원 이름·주민번호·연락처는 입력하지 않습니다.**
- 내장 규칙은 식약처 공식 목록이 아니며 약사·의사의 검토를 받지 않았습니다. 현장에서 쓰기 전에 촉탁의나 약사의 확인을 권합니다.

## 하는 일

1. 약별 정리: 성분, 쓰임, 흔한 부작용, 관찰할 점, 복용 시 주의
2. 함께 복용할 때 확인할 조합
   - 내장 규칙 점검(AI 판단 아님): 병용 주의, 같은 성분 중복, 누적 부담(항콜린 작용, 졸림, 심장 리듬, 혈압 저하)
   - 회원 상태·나이별 주의: 임신 가능성, 전립선비대, 심한 변비, 흡연 등 13가지 상태와 노인 주의
   - AI가 짚은 조합
3. 관찰 체크리스트
4. 관찰된 변화와 약의 관련 가능성
5. 주치의·약사 문의사항과 재활계획 반영 초안
6. 회원에게 설명할 쉬운 말
7. 약 공부하기: 약별 설명, "왜 그런가요?", 질문하기, 퀴즈, 용어 풀이
8. 메모장 파일(.txt)로 저장
9. Claude 사용량이 떨어졌을 때 ChatGPT에 요청문을 복사해 쓰는 대체 경로

## 실행 환경

`index.html` 파일 하나로 되어 있습니다. Claude 안에 올린 페이지(아티팩트)로 열어야 AI 정리, 약 공부, 퀴즈, 사진 읽기, 파일 저장이 작동합니다. 파일을 브라우저에서 직접 열면 화면과 용어 풀이, ChatGPT 대체 경로만 쓸 수 있습니다.

식약처 공식 자료(DUR 병용금기 등)는 연결되어 있지 않습니다. 연결하려면 공공데이터포털 인증키와 별도 서버가 필요합니다.

## 참고한 공개 코드와 라이선스

- 병용 규칙의 구조와 일부 규칙은 [RxCheck](https://github.com/indiser/Rxcheck)(MIT License, Copyright (c) 2026 indiser)의 규칙을 우리말로 옮겨 고쳐 쓴 것입니다. 라이선스 전문은 `index.html` 맨 위 주석에 있습니다.
- 건강 상태 문진 기반 점검, 약별 위험 표시, 노인 약물 점검, 점검 요약은 PillTip(부산대)과 DrugLens의 기능을 참고해 일반 임상 지식으로 따로 작성했으며, 해당 프로젝트의 코드나 데이터는 사용하지 않았습니다.
- 정신과 약 관련 규칙과 용어 풀이는 이 프로젝트에서 직접 작성했습니다.
